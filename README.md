# Engineering Build Lab

A collection of independent, hands-on software engineering challenges. Each starts with a functional application; you implement a focused feature, integration, or engineering improvement yourself.

## Why this lab

Build implementation skill, technical breadth, problem-solving ability, and senior-level judgment through realistic work—not a fixed weekly curriculum or dependent projects. Challenges use synthetic data and target roughly an hour of focused implementation, with flexibility to learn unfamiliar tools.

## How challenges work

Each project lives in its own `challenges/NNN-short-name/` directory with its own dependencies, setup, and runtime. Start from its README and challenge brief, inspect the working baseline, then implement and verify the requested behavior. Challenge requirements are separate from your code and retrospective; projects do not depend on one another. See the [challenge directory](challenges/README.md), [specification template](templates/CHALLENGE.md), [retrospective template](templates/RETROSPECTIVE.md), and [challenge log](CHALLENGE_LOG.md).

## How AI is used

AI scaffolds the working baseline, but does not implement the assigned feature. You own architecture, implementation, tests, and verification. Ask AI for explanations, progressively stronger hints, debugging guidance, or a review; it must not silently change your solution or reveal the full implementation unless explicitly asked. See [AGENTS.md](AGENTS.md) and [SCAFFOLD_PROMPT.md](SCAFFOLD_PROMPT.md).

## Difficulty progression

Challenges begin at Level 1 and increase gradually based on completed work and observed learning needs, from Foundations through Integration, Cross-cutting, Systems, and Advanced. Progression is flexible; challenges remain independent.

## Technology areas

Backend engineering (Python, TypeScript, Node.js), APIs and middleware, databases and data pipelines, AI integrations and agents, LangGraph and RAG, Docker, Kubernetes, Terraform, testing, CI/CD, observability, security, reliability, scalability, and system design.
